# Изменение повторяющихся задач — 27 октября 2026

## Что изменено

В карточке повторяющейся задачи появился выбор:

- только этот экземпляр;
- этот и следующие экземпляры;
- вся серия.

Поддержаны название, дата и время, длительность, правило повторения, включая интервал,
выбранные дни недели и окончание. Для повторяющихся задач используется явное сохранение
кнопкой «Сохранить изменения» или Command+Return. Escape, крестик, «Отмена» и нажатие вне
карточки закрывают черновик без сохранения. Обычные задачи сохраняются автоматически.

Правило повторения доступно при выборе будущих экземпляров или всей серии. Для одного
экземпляра меняются его поля; серия продолжает работать по прежнему правилу.
При повторяющейся серии нельзя очистить дату начала, не задав другую дату или не отключив
повторение. Неподдерживаемое импортированное правило обозначается предупреждением.

Выполненные, пропущенные и удалённые сохранённые экземпляры не перезаписываются.
Другие сохранённые экземпляры также сохраняются по умолчанию: в том числе их название,
время, длительность и отметки. Открытый активный экземпляр получает явно внесённую правку.
Флажок «Заменить индивидуальные правки» разрешает применить **изменённые поля** к другим
активным экземплярам выбранной области. Остальные поля остаются прежними.

В календаре задачи с конкретным временем теперь открываются нативной кнопкой. В дереве
Accessibility доступны название, дата, время, длительность и стабильный идентификатор.
Сокращены области перетаскивания верхнего/нижнего края: середина короткой карточки
доступна для открытия. Задачи на весь день также открываются из календаря.

## Хранение и история

До изменения: ManagedTask с repeatRule — корень серии. RecurrenceProjection вычисляет
будущие задачи календаря. Сохранённый экземпляр связан с корнем через seriesRootID и
occurrenceDate; excludedOccurrences подавляет исходное виртуальное повторение.

Добавлено необязательное поле seriesVersions: массив TaskSeriesVersion(from, template).
Это версии шаблона с границей по неизменной исходной дате экземпляра. Правка будущих
создаёт границу; правка всей серии применяет изменённые поля ко всем версиям, сохраняя
остальные различия между периодами. Шаблоны не содержат вложенных seriesVersions.
Будущие экземпляры по-прежнему вычисляются, отдельные тысячи записей не сохраняются.

Перенос меняет отображаемое время, сохраняя occurrenceDate и ID. Поэтому исключение не
теряется после переноса серии. Календарная арифметика учитывает часовой пояс и переход
летнего/зимнего времени. Независимый дедлайн не меняется при переносе планового интервала.
Сохранённая история и завершённые экземпляры остаются отдельными фактами.

Снимок SQLite содержит новые версии. Поле необязательное: старые снимки читаются без
ручного изменения базы. Undo/redo включает версии серии. Создание независимого дубликата
не копирует внутренние версии исходной серии. Выполнение изменённого корня через
обычное или массовое действие и канбан использует сохранение отдельного экземпляра.
