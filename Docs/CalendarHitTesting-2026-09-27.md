# Границы нажатия календаря и порядок разделов

«Календарь» расположен перед «Задачами» в основной боковой панели. Остальной порядок разделов сохранён.

На пользовательской записи щелчок по боковой панели открывает карточку задачи соседнего дня. Сдвигаемая календарная полоса содержит соседние дни для плавного движения. Прежний `clipped()` ограничивал изображение, но не область обработки нажатий. Полоса теперь имеет прямоугольную `contentShape` по ширине видимого календаря, чтобы скрытые колонки не перехватывали нажатия по боковой панели.

Обработчик закрытия карточки перенесён перед `position`: он измеряет саму карточку, а не всю область, занимаемую позиционирующим контейнером. Это исправляет определение щелчка вне карточки при фокусе в описании.

Автоматические проверки: 98 тестов, один пропущен, ошибок нет. Порядок разделов проверяется существующим тестом модели. Для окончательной ручной приёмки нужны нажатия по боковой панели после горизонтальной прокрутки и по свободному месту после ввода описания.
