# Иерархия импортированных задач

## Причина

Импорт не читал `parentId` и `childIds`. До исправления в локальной базе было 1 763 задачи, без связей `parentTaskID`.

## Изменение

- В импортируемой записи сохраняются исходный ID родителя и ID детей. Поля необязательные для совместимости со старой базой.
- Связи разрешаются после загрузки всех записей, независимо от порядка строк. Дети с отсутствующим родителем остаются доступны; связь восстанавливается, когда родитель появляется в следующем импорте.
- Самоссылки и циклы не создаются. Чек-лист (`items`) сохраняется отдельно.
- При первой синхронизации новая сборка повторно читает историю от самой ранней сохранённой даты выполнения. Перед применением создаётся резервная копия. Существующие ID и согласование локальных правок сохраняются.
- Список показывает дерево и позволяет свернуть ветви. Если фильтр исключил родителя, подходящая подзадача остаётся видимой.
- Карточка показывает родителя и прямых детей. Каждый уровень сохраняет собственные даты и статус.

## Проверки

Автоматически проверены порядок импорта, несколько уровней, выполненный ребёнок, повторный импорт без дублей, сохранение локального названия, отсутствующий родитель, циклы и сворачивание дерева.

## Проверка на пользовательской базе

После синхронизации: 1 766 записей, 455 связей. Сохранены все 1 763 прежних ID; отдельно получены три отсутствовавших родителя. Не разрешённых ссылок на родителя и расхождений между `parentSourceID` и локальным `parentTaskID` нет. Две отменённые родительские задачи сохраняют статус `wontDo`.

88 автоматических тестов, ошибок нет, один отдельный тест реального импорта пропущен. Выполнена реальная синхронизация через запущенное приложение и проверка сохранённой базы. Визуальная приёмка дерева в списке не подтверждена: средство управления возвращает неполное дерево элементов окна, снимок — миниатюру Stage Manager.
