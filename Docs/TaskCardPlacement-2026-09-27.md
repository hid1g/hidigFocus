# Расположение карточки задачи

Карточка перенесена из системного popover общего прозрачного слоя в слой внутри рабочей области задач. Положение рассчитывается от прямоугольника выбранной задачи: справа при наличии места, иначе слева, с ограничением по всем границам окна. Размер раскрытой карточки также ограничен доступным пространством. Закрытие по клику вне карточки сохраняет изменения через существующий обработчик исчезновения.

95 тестов, один пропущен, ошибок нет. Четыре новые проверки: левая задача, правая задача, края с раскрытыми подробностями и маленькое окно.

В работающем приложении визуально подтверждены открытие рядом с задачей «Автоматизировать работу» и удержание раскрытой карточки внутри окна. Системная стрелка popover больше не используется. Дополнительно добавлен обработчик Esc, действующий только в окне открытой карточки; вложенные окна выбора даты и другие диалоги получают свои события.

После последнего обновления открыта задача правой колонки «Задача с поиском», подтверждено закрытие карточки по Esc без фокуса в текстовом поле.
