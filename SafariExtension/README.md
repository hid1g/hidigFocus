# hidigFocus Safari Guard

Исходники Safari Web Extension используют те же правила hidigFocus, что и расширение Chromium.

Для создания содержащего приложения и Xcode-проекта установите полный Xcode и выполните из корня проекта:

```bash
./scripts/build-safari-extension.sh
```

После сборки включите расширение в Safari: Настройки → Расширения → hidigFocus Safari Guard.
