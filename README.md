# hidigFocus

Нативное macOS-приложение для блокировки сайтов и приложений по расписанию или задачам. Локальные задачи работают без внешнего сервиса; TickTick доступен только как источник ручного импорта. Для работы приложения не нужны TickTick, его CLI или аккаунт.

> Проект находится в активной разработке. Текущая версия предназначена для самостоятельной локальной сборки и тестирования.

## Интерфейс — 1 ноября 2026

- Нативная общая верхняя панель macOS: стандартные кнопки окна, управление навигацией и заголовок. В календаре заголовок содержит число, месяц и год выбранной даты, например «1 ноября 2026 г.», с учётом часового пояса календаря.
- На узком окне кнопка навигации открывает боковую панель поверх содержимого. При раскрытии временные интервалы календаря и ширина рабочей области не пересчитываются.
- Индикаторы состояния используют самостоятельные зелёный и красный цвета: включено — зелёный, выключено — красный. Цвет не зависит от акцентного цвета темы; состояние также подписано текстом.
- Стрелка подзадач нажимается в области 32×32 pt, включая пространство вокруг значка. Кнопки выбора и выполнения задачи работают отдельно.
- Общие размеры и отступы кнопок, одинаковая ширина действий подтверждения удаления. Escape и «Отмена» закрывают подтверждение, сохраняя открытую карточку.
- Оформление «Бумага», локальные Golos Text, Onest, Manrope и Inter; варианты светлой и тёмной темы, иконки «Двери» и «Медальон». Существующие настройки масштаба, размера текста и выбранная иконка сохраняются.

Обновление интерфейса не меняет схему задач (`PersistedAppState`, версия 3) и не заменяет пользовательскую базу. Перед установкой следует штатно завершить приложение, сохранить согласованную резервную копию SQLite, журнала, вложений, предпочтений и предыдущей сборки. После запуска сверить ID и все поля задач. Для отката заменяется приложение; старую базу нельзя автоматически восстанавливать поверх новых пользовательских изменений.

Проверки запускаются на отдельной копии данных через `HIDIGFOCUS_DATA_DIR`, отдельный `HIDIGFOCUS_PREFS_SUITE` и `HIDIGFOCUS_QA=1`. Изолированная сборка не выполняет реальные блокировки, уведомления и сетевые изменения. Тесты и снимки интерфейса не доказывают выполнение кадровых нормативов: полная приёмка всех 232 макетов, VoiceOver, реальный внешний drag-and-drop и запуск на macOS 13 требуют отдельных проверок.

После замены приложения Dock может удерживать старую версию своего модуля. Проверяется путь реально загруженного модуля и ресурс выбранной иконки; обновлять базу или сбрасывать выбранный значок для этого не нужно.

Локальная проверка этой итерации: 270 тестов, 268 прошли, два намеренно пропущены. [Проверенный объём и ограничения](Docs/Interface-2026-11-01.md).

## Планировщик

Карточка открывается рядом с нажатой задачей. Название, описание, список и метки сохраняются автоматически; дата и интервал начала/окончания меняются в отдельном окне. Основная навигация сворачивается до иконок, обе боковые панели можно скрывать и менять их ширину.

Календарь поддерживает день, четыре дня, неделю, месяц и повестку. Пересекающиеся интервалы занимают отдельные колонки. Карточка следует за курсором при переносе; время сохраняется с шагом 15 минут и показывается над карточкой. Перенос меняет плановый интервал и сохраняет независимый дедлайн, растягивание нижней границы меняет длительность с шагом 15 минут. Кнопки «Список», «Календарь» и «Матрица» нажимаются по всей площади.

В окне даты задачи можно настроить локальные повторения: ежедневно, еженедельно, ежемесячно или ежегодно, с интервалом, выбранными днями недели и датой окончания. После выполнения создаётся следующая задача с теми же настройками и сброшенными отметками чек-листа; выполненная задача остаётся в истории. Поддерживаемые будущие повторения вычисляются для диапазона календаря без сохранения тысяч копий. Поддерживаемые импортированные правила повторения выполняются локально без TickTick. Для неподдерживаемого правила можно выбрать локальное повторение в редакторе.

В карточке повторяющейся задачи доступны три области изменения: только этот экземпляр,
этот и следующие экземпляры, вся серия. Повторяющиеся задачи сохраняются кнопкой
«Сохранить изменения» или Command+Return; Escape и «Отмена» закрывают черновик.
Можно изменить название, дату/время, длительность и правило повторения. Правило меняется
для будущих или всей серии. Выполненные, пропущенные и удалённые экземпляры сохраняются.
Индивидуальные правки других сохранённых экземпляров сохраняются по умолчанию; флажок
«Заменить индивидуальные правки» разрешает применить изменённые поля и к ним.
Подробности и проверка: [Docs/RecurringTaskSeries-2026-10-27.md](Docs/RecurringTaskSeries-2026-10-27.md).

TickTick используется только для ручного импорта в разделе «Интеграции». При запуске приложения и по таймеру обращения к TickTick не выполняются. Авторизация проверяется по кнопке на экране импорта; вход сам по себе задачи не переносит. Подготовка показывает найденные данные, отдельная кнопка добавляет их после создания резервной копии.

Повторный импорт добавляет отсутствующие задачи; существующие задачи, списки, статусы и локальные правки сохраняются. Название источника и исходный ID нужны для истории импорта и защиты от дублей. Обратной отправки изменений в TickTick нет. Отключение доступа к импорту не удаляет локальные данные. Календарь, выполнение задач и блокировки используют сохранённые задачи hidigFocus независимо от аккаунта и давности импорта.

## Быстрые задачи и помодоро

В помодоро доступны пары фокус/отдых 25/5, 30/5, 45/10, 50/10 и 60/15 минут. Кнопка времени рядом с выбором интервала открывает пресеты и ввод своих значений. Настройка сохраняется для всех окон; во время запущенной сессии её изменение заблокировано.

Панель строки меню содержит прокручиваемый список задач выбранного дня, выполненную историю, быстрый ввод, месячный календарь и помодоро. Привычки доступны в отдельном разделе основного приложения. Панель также открывается отдельным окном «Быстрые задачи» через меню «Окно».

В основном приложении есть разделы «Календарь» и «Помодоро». Таймер общий для основного окна, панели и отдельного окна: фокус, короткий и длинный перерыв, пауза, продолжение, секундомер, выбор задачи или свободная сессия. Обратный отсчёт записывает завершённую сессию один раз. Часы обновляют только свою часть интерфейса.

Карточка задачи открывается рядом с выбранной задачей и удерживается внутри рабочей области. Для повторяющейся задачи сохранение подтверждается явно; Escape и «Отмена» закрывают черновик. При открытом подтверждении удаления отменяется сначала подтверждение, а карточка остаётся открытой.

## Требования к системе

1. macOS 13 или новее.
2. Полный Xcode, установленный из App Store.
3. Для интеграции с TickTick: Node.js, npm и официальный TickTick CLI:

   ```bash
   npm install -g @ticktick/ticktick-cli
   ticktick auth login
   ```

## Быстрый старт

Клонируйте репозиторий и соберите приложение:

```bash
git clone https://github.com/hid1g/hidigFocus.git
cd hidigFocus
./scripts/build-app.sh
open dist/hidigFocus.app
```

Скрипт создаёт `dist/hidigFocus.app` и подписывает его локальной ad-hoc подписью. Платный аккаунт Apple для запуска на собственном Mac не нужен.

Для создания установочного образа с ярлыком папки «Программы»:

```bash
./scripts/build-dmg.sh
```

По умолчанию собирается оптимизированный вариант `release`. Явный выбор конфигурации:

```bash
HIDIGFOCUS_BUILD_CONFIGURATION=release ./scripts/build-app.sh
```

## Блокировка сайтов

1. Запустить hidigFocus.
2. На экране TickTick или в Настройках нажать «Показать папку расширения».
3. Открыть `chrome://extensions`, `edge://extensions` или `brave://extensions`.
4. Включить режим разработчика.
5. Нажать «Загрузить распакованное» и выбрать папку `BrowserExtension`.

После сборки отдельная готовая папка расширения лежит в `dist/hidigFocus Browser Extension`, а архив для переноса — в `dist/hidigFocus-browser-extension.zip`. Архив необходимо сначала распаковать.

Расширение получает список закрытых доменов от локального адреса `127.0.0.1:17321`. Если приложение перестало отвечать, расширение сохраняет последние правила, а не снимает блокировку.

## Safari

Готовое приложение-контейнер находится в `dist/hidigFocus Safari.app`, архив для установки — в `dist/hidigFocus-safari-extension.zip`. Исходники Safari Web Extension находятся в `SafariExtension`, их отдельный архив — в `dist/hidigFocus-safari-extension-source.zip`.

Для создания устанавливаемого Safari-расширения нужен полный Xcode. После установки один раз откройте Xcode и примите лицензию, затем:

```bash
./scripts/build-safari-extension.sh
```

Скрипт создаст Xcode-проект через официальную утилиту Apple, соберёт приложение и сформирует архив. Запустите `hidigFocus Safari.app`, затем включите расширение в `Safari → Настройки → Расширения`.

Чтобы установить собранный модуль в папку «Программы» и зарегистрировать расширение:

```bash
./scripts/install-safari-extension.sh
```

## Технические границы текущей версии

- hidigFocus может завершать выбранные приложения обычным системным запросом, но не использует системное расширение Apple Family Controls. Приложение, которое игнорирует завершение, может остаться открытым.
- Пользователь macOS всё равно может удалить браузерное расширение или завершить hidigFocus. Абсолютный запрет без административных прав и системного расширения невозможен.
- Задачи блокировки на сегодня определяются по локальному плану hidigFocus; пустой набор не открывает заблокированную группу.

## Разработка и тесты

Проект собран на SwiftUI и Swift Package Manager. Для локальной проверки:

```bash
swift test
```

Основные каталоги:

- `Sources` — macOS-приложение;
- `Tests` — модульные тесты;
- `BrowserExtension` — расширение для Chrome, Edge и Brave;
- `SafariExtension` — исходники Safari Web Extension;
- `scripts` — сборка приложения, DMG и Safari-расширения.

## Данные и приватность

Настройки, задачи, привычки, статистика и журнал хранятся локально на Mac. Интеграция с TickTick работает через отдельно установленный и авторизованный TickTick CLI. hidigFocus не содержит серверной части и не отправляет пользовательские данные на собственный сервер.
