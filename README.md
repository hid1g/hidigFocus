# hidigFocus

Нативное macOS-приложение для блокировки сайтов и приложений по расписанию или задачам. Локальные задачи работают без внешнего сервиса; TickTick подключается как необязательный источник.

> Проект находится в активной разработке. Текущая версия предназначена для самостоятельной локальной сборки и тестирования.

## Что реализовано

- группы блокировки по расписанию, задачам или обоим условиям;
- расписания на каждый день, будни, выходные и выбранные дни;
- локальные задачи hidigFocus без обязательного подключения TickTick;
- произвольные домены и macOS-приложения в каждой группе;
- сверка задач TickTick каждую минуту;
- привычки с дневными отметками и текущими сериями;
- подтверждаемое отключение защиты с обнулением текущих серий;
- Markdown-журнал в `~/Library/Application Support/hidigFocus/Journal`;
- локальная статистика без искусственных демонстрационных данных;
- локальное расширение для Chrome, Edge и Brave;
- светлая, тёмная и системная темы;
- навигация по неделям и восстановление отметки за вчера;
- переименование Markdown-файлов и инструкция для Obsidian;
- фирменная иконка и бесплатная локальная подпись приложения;
- компактная панель в строке меню macOS;
- запуск вместе с macOS и опциональное скрытие значка в Dock;
- группировка задач TickTick по проектам, поиск и фильтры;
- настраиваемые шрифты, размер текста, общая цветовая палитра и четыре варианта иконки;
- исходники Safari Web Extension с отдельной проверкой подключения.

## Требования

1. macOS 13 или новее.
2. Полный Xcode, установленный из App Store.
3. Для интеграции с TickTick: Node.js, npm и официальный TickTick CLI:

   ```bash
   npm install -g @ticktick/ticktick-cli
   ticktick auth login
   ```

## Быстрый старт

Клонируйте репозиторий и соберите приложение:

```bash
git clone https://github.com/hid1g/hidigFocus.git
cd hidigFocus
./scripts/build-app.sh
open dist/hidigFocus.app
```

Скрипт создаёт `dist/hidigFocus.app` и подписывает его локальной ad-hoc подписью. Платный аккаунт Apple для запуска на собственном Mac не нужен.

Для создания установочного образа с ярлыком папки «Программы»:

```bash
./scripts/build-dmg.sh
```

По умолчанию используется надёжная debug-сборка. После установки полного Xcode release-вариант собирается так:

```bash
HIDIGFOCUS_BUILD_CONFIGURATION=release ./scripts/build-app.sh
```

## Блокировка сайтов

1. Запустить hidigFocus.
2. На экране TickTick или в Настройках нажать «Показать папку расширения».
3. Открыть `chrome://extensions`, `edge://extensions` или `brave://extensions`.
4. Включить режим разработчика.
5. Нажать «Загрузить распакованное» и выбрать папку `BrowserExtension`.

После сборки отдельная готовая папка расширения лежит в `dist/hidigFocus Browser Extension`, а архив для переноса — в `dist/hidigFocus-browser-extension.zip`. Архив необходимо сначала распаковать.

Расширение получает список закрытых доменов от локального адреса `127.0.0.1:17321`. Если приложение перестало отвечать, расширение сохраняет последние правила, а не снимает блокировку.

## Safari

Готовое приложение-контейнер находится в `dist/hidigFocus Safari.app`, архив для установки — в `dist/hidigFocus-safari-extension.zip`. Исходники Safari Web Extension находятся в `SafariExtension`, их отдельный архив — в `dist/hidigFocus-safari-extension-source.zip`.

Для создания устанавливаемого Safari-расширения нужен полный Xcode. После установки один раз откройте Xcode и примите лицензию, затем:

```bash
./scripts/build-safari-extension.sh
```

Скрипт создаст Xcode-проект через официальную утилиту Apple, соберёт приложение и сформирует архив. Запустите `hidigFocus Safari.app`, затем включите расширение в `Safari → Настройки → Расширения`.

Чтобы установить собранный модуль в папку «Программы» и зарегистрировать расширение:

```bash
./scripts/install-safari-extension.sh
```

## Технические границы текущей версии

- hidigFocus может завершать выбранные приложения обычным системным запросом, но не использует системное расширение Apple Family Controls. Приложение, которое игнорирует завершение, может остаться открытым.
- Пользователь macOS всё равно может удалить браузерное расширение или завершить hidigFocus. Абсолютный запрет без административных прав и системного расширения невозможен.
- В выборку TickTick входят задачи, у которых дата выполнения приходится на сегодня. Просроченные задачи без сегодняшней даты в эту выборку не входят.

## Разработка и тесты

Проект собран на SwiftUI и Swift Package Manager. Для локальной проверки:

```bash
swift test
```

Основные каталоги:

- `Sources` — macOS-приложение;
- `Tests` — модульные тесты;
- `BrowserExtension` — расширение для Chrome, Edge и Brave;
- `SafariExtension` — исходники Safari Web Extension;
- `scripts` — сборка приложения, DMG и Safari-расширения.

## Данные и приватность

Настройки, задачи, привычки, статистика и журнал хранятся локально на Mac. Интеграция с TickTick работает через отдельно установленный и авторизованный TickTick CLI. hidigFocus не содержит серверной части и не отправляет пользовательские данные на собственный сервер.
